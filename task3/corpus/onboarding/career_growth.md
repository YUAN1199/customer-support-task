# Career Growth Framework

## Document ID: ONB-006
## Min Role: intern

## Overview

AcmeCorp believes in transparent career growth paths. This framework outlines how to progress through engineering levels.

## Engineering Competencies

### Technical Skills
- Code quality and testing
- System design and architecture
- Debugging and troubleshooting
- Performance optimization
- Security awareness

### Delivery
- Project estimation and planning
- Breaking down complex tasks
- Managing dependencies
- Stakeholder communication
- On-time delivery

### Collaboration
- Code reviews (giving and receiving)
- Mentoring junior engineers
- Cross-team collaboration
- Documentation
- Knowledge sharing (tech talks, RFCs)

## Promotion Process

1. Self-nomination or manager nomination
2. Promotion packet: 3-5 projects demonstrating next-level impact
3. Peer feedback: 4+ reviewers
4. Calibration committee review (quarterly)
5. Decision communicated within 2 weeks

## Timeline

- L1 → L2: Typically 12-24 months
- L2 → L3: Typically 18-36 months
- L3 → L4: Typically 24-48 months
- L4 → L5: Varies significantly
